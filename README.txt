THE MISSION SCHOOL, RANIGANJ — WEBSITE

Files:
- index.html: complete responsive single-page school website
- style.css: styling and mobile responsive layout
- script.js: mobile navigation, active section highlighting and demo enquiry form

HOW TO VIEW
1. Extract the ZIP file.
2. Open index.html in a browser.

BEFORE PUBLISHING
- Replace sample Unsplash photographs with actual school photographs that the school is authorized to use.
- Confirm the school's official address, phone number, email, classes, curriculum and admission details.
- Connect the enquiry form to an approved email service or backend. It currently demonstrates the interface only and does not send or store enquiries.
- Add the school's verified logo and social media links.
- Check photo permissions and obtain appropriate consent before publishing identifiable student photographs.

This is a responsive one-page website with navigation tabs/sections: Home, About Us, Programs, Admission, Gallery and Contact Us.

3D ENHANCEMENTS
- Floating 3D school crest/orbit graphic in the hero section.
- Perspective hover effects on program cards, value cards, gallery photos and admission panel.
- 3D-style school logo crest interaction.
- Motion respects the visitor's reduced-motion accessibility setting.
